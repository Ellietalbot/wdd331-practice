Drafting an icon by hand

A rocket built from four primitives and a seven-command path — no library, no copied markup. Every line below is annotated like a blueprint so you can see the coordinates doing the work.

01 viewBox vs. rendered size

Same coordinates, two sizes

Both icons below share viewBox="0 0 24 24". Only the CSS width changes. The internal grid stretches to fill whatever box you give it.

64 × 64
160 × 160

viewBox="0 0 24 24" stays fixed. The browser scales 24 internal units to whatever pixel width the CSS sets — 2.67px/unit on the left, 6.67px/unit on the right.
